# New Book Ideas

A collection of book (and script) ideas, each developed from raw brainstorm notes into a full outline. Every project folder under `book-ideas/` contains two files:

- **`original-notes.md`** — the original brainstorm notes, reproduced in full and unedited, for reference and provenance.
- **`outline.md`** — a full outline built from those notes: logline, genre/comps, themes, characters, structure, and craft notes flagging open decisions or gaps in the source material.

Where the source notes were sparse, the outline says so explicitly and marks which parts are original extrapolation versus sourced content — treat those outlines as a strong first draft to react to, not a transcription of notes that exist elsewhere.

## Notable cross-project connections
A few projects share DNA worth knowing about before developing any of them further:
- **#08 (Monsieur Zhivakov)** and **#10 (Book 2: Perfect)** both feature a wolf bounty hunter named Monsieur Géroux/Bernard Géroux with a wife and children and a restraint-based combat philosophy — likely either a shared-universe reuse or two drafts of the same character concept. Worth reconciling before drafting either.
- **#10 (Book 2: Perfect)** is explicitly a sequel pitch for an already-drafted manuscript ("The King and the Red Evil," multiple versions of which exist in the source Drive account) — its outline should be read alongside that manuscript, not standalone.
